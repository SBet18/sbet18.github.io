ESP32 Automated Irrigation Controller

Embedded monitoring and pump-control logic using a soil sensor, water-level measurement and configurable watering settings.

ESP32MicroPythonSensorsAutomation

Sensor–controller–relay system overview.

Project overview

As part of a two-person greenhouse automation project at ENIM, I developed the soil-moisture and irrigation-control module on an ESP32 with MicroPython. The system reads moisture levels and reservoir conditions, then runs configurable rules to activate irrigation through a relay-controlled water pump.

Architecture and logic

The software organises the behaviour into a controller class, integrating a capacitive soil moisture sensor and an analog water-level sensor. It supports optimal-range checks, low-water alerts, irrigation frequency and volume settings, and moisture-driven adjustments to watering duration/frequency.

Testing and deliverables

I also wrote function-level tests to check the controller's logic before integration. The public repository currently contains the README and two Python files; the test suite is described in the project notes but is not currently published in that repository.

What it demonstrates

  • Object-oriented MicroPython design for an embedded controller.
  • Sensor readings and threshold-based decisions.
  • Actuator control via relay and handling low-reservoir conditions.
  • Functional testing before system integration.

ENIM team of two. The available evidence documents the controller module, not a field-proven complete greenhouse installation.
